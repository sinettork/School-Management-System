REMAINING ISSUES (AUDIT FINDINGS)
---------------------------------
1. CRUD depth
   - Core academic modules now have edit/delete
   - Fee Payments and Notices are list/add only
   - No view/detail pages for any entity

2. UI/UX gaps
   - Attendance uses hardcoded Tailwind colors (emerald/rose/amber)
     that don't match the navy/gold theme. Should use CSS variables.
   - Attendance table does not yet have pagination.

3. Database / Backend
   - Only 1 RLS policy exists (students table admin policy)
   - Missing RLS for: teachers, classes, subjects, attendance, exams, exam_results, fee_payments, notices
   - Missing unique constraint on attendance (student_id + attendance_date)

4. Architecture
   - No data export (CSV/Excel) functionality

5. Theme consistency
   - Attendance summary cards use hardcoded emerald/rose/amber utility colors.
   - Dashboard chart uses `var(--color-primary)`, but could use the gold accent for contrast
